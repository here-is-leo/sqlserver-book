# English

## 📖 About the Book

> A practical SQL Server reference that starts with the first `SELECT` and finishes with execution plans, concurrency, security, analytics, and production scenarios.

**SQL Server Book** is a 51-page online book for learners who want depth without setup friction. Its content, navigation, themes, and progress tracking live in one portable HTML file.

| Feature | What you get |
|---|---|
| Bilingual | Complete English LTR and Persian RTL editions |
| Full learning path | Fundamentals through professional practice |
| Focused depth | 12 sections and 51 pages |
| Two themes | Dark and light themes with saved preferences |
| Responsive | Mobile, tablet, and desktop support |
| Fast navigation | Keyboard controls and reading progress |
| Print ready | Dedicated print stylesheet |
| Portable | No dependency or build step |

## 💡 Why This Book?

1. **One coherent path:** learn in sequence instead of stitching together disconnected articles.
2. **Production-minded:** connect queries to design, security, concurrency, and performance.
3. **Genuinely bilingual:** switch languages without losing technical context.
4. **Open anywhere:** read offline, host it, or share one file without a toolchain.

## ⚖️ Comparison

| Resource | Learning path | Best use |
|---|---|---|
| **SQL Server Book** | Beginner to advanced in 12 ordered sections | Bilingual, interactive, offline study |
| Official documentation | Comprehensive reference, not a single course | Exact feature lookup |
| Video courses | Instructor-dependent | Guided visual learning |
| Blog posts | Isolated topics | Quick answers |

> This book complements—not replaces—Microsoft documentation, hands-on practice, and production experience.

## 🚀 Getting Started

**Online:** [Open the live book](https://here-is-leo.github.io/sqlserver-book/).

**Local:**

```bash
git clone https://github.com/here-is-leo/sqlserver-book.git
cd sqlserver-book
```

Open `index.html` in a modern browser.

**Embed:**

```html
<a href="https://here-is-leo.github.io/sqlserver-book/">Read SQL Server Book</a>
```

> **No `npm install`. No build step.** Clone, open, and read.
