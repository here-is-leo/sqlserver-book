> A practical SQL Server reference that starts with the first `SELECT` and finishes with execution plans, concurrency, security, analytics, and production scenarios.

<div dir="rtl">

> مرجعی کاربردی برای SQL Server؛ از نخستین دستور <code>SELECT</code> تا پلن اجرایی، هم‌زمانی، امنیت، تحلیل داده و سناریوهای واقعی محیط تولید.

[Open the live book](https://here-is-leo.github.io/sqlserver-book/)—the fastest way to start.

```bash
git clone https://github.com/here-is-leo/sqlserver-book.git
cd sqlserver-book
```

Then open `index.html` in a modern browser.

<div dir="rtl">

سپس فایل <code>index.html</code> را در یک مرورگر مدرن باز کنید.

</div>

```html

  Read SQL Server Book
</a>
```

<div dir="rtl">
